# Frozen selector protocol (declared before final evaluation)

**Experimental; not independently validated.** Fresh own-machine and cross-machine evaluation runs were prepared but not completed. The earlier cross-machine result is development evidence only; the artificial-label smoke test verifies wiring, not model selection reliability. The 0.01 threshold has not been established on independent generators.

For each independent generator scenario, fit the existing Thanos E2 and shared-base+polarity+pol-logistic candidates using only allowed histories. Compute forecasts at the training query cutoffs. None of the training query labels may enter either candidate's fit. For each training episode compute mean one-hot 5-category Brier(polarity) minus Brier(Thanos). Resample whole episodes 5,000 times with fixed seed 811, stratified by training condition. Switch to polarity only if the upper 95% confidence bound is below -0.01 Brier. Otherwise default to Thanos, conditional on a separately verified package; if unavailable, retain the existing verified shared-base entry. The 0.01 threshold is a predeclared conservative choice, not optimized from final episodes.

Only after BOTH decisions are written, score once on separate held-out synthetic episodes against true probabilities; resample whole episodes stratified by condition. Distinguish one-hot training outcome Brier from squared error to true held-out probabilities. Train and evaluation episodes are disjoint. Both models may fit hyperparameters to pre-cutoff held-out histories (transductive, permitted); no held-out query outcome or target enters fitting or selection. This measures selection under that transductive protocol, not an inductive fit.

Scenarios: (1) own-machine XOR pairs from the existing synth_kit.py, seed 22611; (2) neighbor-lag synthetic generator from prior stress, seed 22612. Different seeds from all previously inspected data. One seed per scenario is not enough to estimate real-world false-selection probabilities; report outcomes and uncertainty without extrapolating a rate.
