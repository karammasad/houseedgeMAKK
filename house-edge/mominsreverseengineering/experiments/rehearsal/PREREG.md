# Round 2 rehearsal: pre-registration (written BEFORE any model saw the synthetic kit; hidden truth never opened until both models are frozen)
Kit: gen_round2.py, seed 20261108, ONE configuration (see its docstring): changed lag structures (pairs (1,5)/5, (2,3)/2, (3,8)/8, (4,6)/4, single (3)/3, none), shifted rates and gamma, shifted size vectors, four conditions (train 24 / validation 24 / test 48 episodes per condition, 8 machines per episode, 40+24 short layout).
Models, both FROZEN with default settings, transductive (histories of train+validation+test), no selection step, no labels or conditions used:
  T = Thanos E2 (origin/main thanos/, `python3 -m thanos.run --splits all --tickset own`, 2 threads), unmodified code.
  F = our practical fallback: method4_ml v9 + shared-base (`Model(shared_base=True)`, default settings, 2 workers, 2 BLAS threads), no adapt.py selection.
Evaluation set: the 1,536 test queries (192 episodes). Primary metric: mean squared distance of the predicted 5-vector to the TRUE probability vector (no outcome noise), paired by episode, 95% episode bootstrap. Secondary: 5-class Brier against the realized outcome, per condition, per type. Runtime: wall seconds of each end-to-end run (fit + test predict) with 2 threads.
Decision rule (GO for Thanos as Round 2 primary): primary paired difference F - T > 0 with episode-bootstrap P >= .95, AND no condition worse by more than 5% relative, AND runtime < 20 min on 2 cores. If it fails, identify the specific failure and propose only the smallest adaptation. Nothing here is tuned on Round 1 validation/audit or any previously used synthetic set.
