# Pre-registration: validation of the no-gate adaptation (written BEFORE any run; the first rehearsal kit's test outcomes are spent and are NOT reused)
Adaptation: `nogate_fix.apply(egp)` = add one no-gate candidate ((), size lag 1, initial mass .05) to Thanos' structure support; nothing else changes (Thanos 8e00a50 code unmodified, same tickset "own", same threads).
Test A (fresh synthetic kit): gen_round2.py, SAME frozen configuration, new seed 20261109, hidden truth outside the kit. T0 = frozen Thanos E2, T1 = Thanos + fix, both `--splits all`, 2 threads. Metric: squared distance to the TRUE vector on the 1,536 test queries, paired by episode (192), 95% bootstrap.
  ADOPT only if (i) overall T1 - T0 improvement has CI excluding 0 (episode bootstrap P >= .95), (ii) on machines that truly have a gate, T1 - T0 worsening has 95% upper bound <= 1.0e-4, (iii) runtime overhead <= 25%.
Test B (real Round 1 TRAIN, no validation/audit): Thanos' own 4-fold episode-grouped CV (train histories of the other folds, held-out outcomes at c..c-3, 5-class Brier) T0 vs T1. ADOPT-SAFE only if the paired difference T1 - T0 has upper 95% bound <= +3e-4 (no harm) overall; also report the learned prior mass of the no-gate structure and mu_n / ls_n per type (whether real data supports the class).
Both must pass for the fix to be recommended. No parameter of either model is tuned. Official Round 1 validation / audit are not used.
